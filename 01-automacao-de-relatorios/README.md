# Projeto 01 — Automação de Relatórios Comerciais

## Objetivo
Desenvolver uma automação para organizar dados comerciais e facilitar a geração de relatórios.

## Problema
Processos manuais de organização e análise de dados podem consumir tempo e dificultar o acompanhamento de indicadores.

## Ferramentas previstas
- Google Sheets
- Make
- ChatGPT
- Gmail

## Como funcionará
1. Recebimento dos dados em uma planilha.
2. Organização das informações.
3. Processamento automatizado.
4. Geração de um resumo.
5. Envio do relatório.
